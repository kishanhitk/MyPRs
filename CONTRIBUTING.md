# Contributing to MyPRs

Thanks for your interest! Issues and pull requests are welcome.

## Setup

See the [Local development](README.md#local-development) section of the
README. Short version: `bun install`, `supabase start`, copy `.env.example`
to `.env.local`, then `bun run dev`.

## Before you open a PR

- Run `bun run typecheck` and `bun run lint` — both must pass.
- Keep PRs focused: one change per PR.
- For new features, open an issue first so we can discuss the approach.

## Reporting bugs

Open an issue with steps to reproduce, what you expected, and what happened.
Screenshots help for UI issues.
